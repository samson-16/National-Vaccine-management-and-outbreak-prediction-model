# Measles Outbreak MVP Dataset Pipeline

This workspace builds a practical Ethiopia woreda-month measles outbreak dataset for a final-year ML project.

The current pipeline uses:

- The provided EPHI measles workbook as the primary real Ethiopia label source.
- Public external-country measles data as support data for outbreak-shape learning.
- Manually downloaded public files in the project root, including WHO reported cases and Ethiopia admin boundaries.
- A removable synthetic label overlay for MVP completeness.
- Explicit provenance flags so fake labels can be filtered out instantly.

## Easy Synthetic Removal

Synthetic/fake labels are intentionally easy to remove.

Fast filter:

```text
synthetic_flag == 0
```

Export a no-synthetic file:

```powershell
python scripts/filter_measles_dataset.py --remove-synthetic --output data/processed/measles_no_synthetic.csv
```

Export a no-synthetic file and delete the provenance flag columns too:

```powershell
python scripts/filter_measles_dataset.py `
  --remove-synthetic `
  --drop-flag-columns `
  --output data/processed/measles_no_synthetic_no_flags.csv
```

Train only on real EPHI labels:

```powershell
python scripts/filter_measles_dataset.py `
  --real-only `
  --output data/processed/measles_real_ephi_only.csv
```

## Important Label Types

```text
real_ephi           Real labels from the provided EPHI measles workbook.
weak_public_report  Reserved for public outbreak reports when extracted.
synthetic_model     Fake positive/outbreak labels generated by the MVP risk model.
synthetic_negative  Fake negative/non-outbreak labels generated by the MVP risk model.
unknown             Unlabeled rows before the synthetic overlay is applied.
external_public     Non-Ethiopian public support data.
```

## Flag Columns

```text
real_flag
weak_label_flag
synthetic_flag
imputed_flag
guessed_flag
external_country_flag
ethiopia_flag
```

Use `synthetic_flag == 0` for academically safer analysis. Use the mixed dataset only for MVP/demo training unless you clearly state that synthetic labels were included.

## Demo Training File

For model training demos, use:

```text
data/processed/measles_training_demo_model_matrix.csv
```

This file keeps the model-facing columns clean and does not include provenance/flag columns. The matching audit sidecar is:

```text
data/processed/measles_training_demo_provenance.csv
```

Join the two files by `location_id` and `period_start` if you need to inspect where a label came from.

## Current Limitations

The current location reference now uses exact COD-AB admin3 p-code matches where EPHI names align, but unmatched woreda names still need manual alias cleanup. Public rasters/APIs such as WorldPop, CHIRPS, and healthcare access layers are represented by deterministic proxy features for now. The report at `reports/modeling_readiness_report.md` explains what the dataset can and cannot support.

If an output file is open in Excel, the scripts write a `_new.csv` fallback instead of failing.
